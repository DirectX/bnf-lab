Соответствие механическое: каждому нетерминалу — своя функция. Левая рекурсия превращена в цикл: записать её напрямую нельзя — функция вызвала бы себя первой строкой; цикл даёт левую ассоциативность, которую требовала грамматика.

              Границы генератора и что дальше по методичке
              

                
Один аккумулятор во плоти: вложенные выражения сохраняются
                  PUSH/POP, константы едут в память — ADD принимает только адрес,
                  умножение разворачивается циклом сложений, а a <= b — перебором вниз,
                  потому что у машины нет флага «меньше». Всё это видно в листинге под своими комментариями.

                
Честные отказы: деление и константы > 255 генератор
                  не компилирует — с внятным объяснением. Деление циклом вычитаний — самостоятельная работа.

                
Дальше (занятие 3): тот же язык через bison — экспорт в
                  .y, конфликт сдвиг/свёртка на висячем else, замер стоимости изменения языка.

Часть 3. Рукописный парсер против генератора. Конфликты и стоимость изменения

              в планах
            

            

              По методическим указаниям к занятию 3: основание для инженерного выбора —
              не чужое мнение, а собственный замер. И конфликт сдвиг/свёртка перестаёт
              быть словами с лекции.
            

            

              
Экспорт в .y. Грамматика из части 1 переносится
                в файл bison — левая рекурсия записывается напрямую, без переписывания в цикл.

              
Два исполнителя грамматики. Быстрый — генератор LALR
                на чистом JS (jison) прямо в браузере: конфликт сдвига/свёртки на висячем else
                виден мгновенно и без сервера. Полный — настоящий bison на отдельном Node-бэкенде:
                фронтенд остаётся статическим, .y компилируется там, где можно ставить
                yacc-утилиты. Эталонные отчёты bison для готовых грамматик может генерировать
                и сам GitHub Actions при сборке.

              
Конфликт сдвиг/свёртка вживую. Тот же «висячий else»,
                который анализатор части 1 уже помечает, bison покажет как реальный конфликт — с разбором сообщения.

              
Бланк замера. Строк кода, время реализации, время внесения
                изменения в язык, число затронутых мест — в рукописном и bison-вариантах.

              
Вывод. Малый и стабильный язык — рукописный спуск дешевле;
                большой и меняющийся — генератор окупается.
