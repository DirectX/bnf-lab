# Референсные решения (Python) — занятия 1 и 2

Эталонный код, который студенты пишут по шагам 1 и 2 Tema 4. Запуск —
из этой папки, зависимостей нет (только стандартная библиотека, Python 3.8+):

```bash
python3 zanyatie1_lexer.py            # лексер + самопроверка (блок 5 занятия 1)
python3 zanyatie2_parser_codegen.py   # парсер + генератор + эмулятор, самопроверка
python3 zanyatie2_etalonnye_testy.py  # эталонные тесты: программа → память (блок 6 занятия 2)
```

Или одной командой из корня проекта: `npm run pytest`.
Код возврата 0 — всё прошло; ненулевой — есть падения (требование блока 6).

## Как это соотносится с веб-лабораторией

Каждый файл — самостоятельная реализация того же конвейера, что работает в
приложении, и он **сверяется с ним побайтово**:

- `etalon-js.json` — байтовые эталонные листинги, снятые с приложения
  (`npm run gen-etalon`, генерируется из `src/cpu8/codegen.js`);
- `zanyatie2_parser_codegen.py` при запуске компилирует те же семь программ
  и сверяет свои байты с эталоном. Совпадение полное (включая программу
  пресета — 211 байт, 1589 шагов) означает: листинг, полученный в Python,
  можно копировать на [tinycpu-web](https://directx.github.io/tinycpu-web/)
  один в один, как и листинг из веб-версии.

## Содержимое

### `zanyatie1_lexer.py` — занятие 1, блок 4

Лексер мини-языка. Граница модуля, которую требует занятие: лексер **не знает
про грамматику** — `) ) + = while` для него корректный вход.

Покрывает все «затыки», к которым преподавателю велено готовиться:

- ключевое слово против идентификатора: `while1` — идентификатор (максимум
  букв/цифр читается первым, таблица ключей проверяется после);
- многосимвольные операции: `<=` — одна лексема (максимальное совпадение);
- `12abc`: переключатель `strict_numbers` — ошибка или два токена, решение
  записано и покрыто тестом;
- позиция (строка, столбец) у каждой лексемы — без неё парсер не скажет, где ошибка;
- восьмибитный тип: `256` помечается замечанием (лексер пропускает, генератор откажет);
- комментарии `//` и `/* */` — переключателем (это перенос в самостоятельную работу).

Встроенная самопроверка — пограничные и негативные случаи блока 5.

### `zanyatie2_parser_codegen.py` — занятие 2, блоки 1–5

Парсер рекурсивного спуска + генератор кода TinyCPU-8 + эмулятор (порт
`reference/tinycpu.py`). Сюжеты занятия, воплощённые в коде:

- **правило → функция** — соответствие механическое, по одному методу на нетерминал;
- **левая рекурсия → цикл** (`_binary`): записанная напрямую `parse_expr`
  вызвала бы себя первой строкой; цикл даёт левую ассоциативность;
- **разбор отделён от вычисления**: в парсере нет арифметики, он строит дерево;
- **скобок в AST нет** — они растворились в форме дерева;
- **ошибки с позицией**: `ParseError` несёт строку/столбец и список ожидаемых
  лексем (тот самый случай «пять минут сейчас экономят час потом»);
- генератор: **PUSH/POP** при одном аккумуляторе, **константы в памяти**
  (`ADD` не умеет immediate), **умножение циклом сложений** (в машине нет MUL),
  **сравнение перебором вниз** (нет флага «меньше»), **адрес вперёд двумя
  проходами** — обратная правка;
- честные отказы: деление и константы > 255.

### `zanyatie2_etalonnye_testy.py` — занятие 2, блок 6

Приём из Темы 3: программа → эталонное состояние памяти. 6 позитивных тестов
(один обязательно с циклом — проверяет адреса переходов, самое хрупкое место)
и 3 негативных (компилятор обязан отказаться, а не скомпилировать мусор).
Отдельная проверка: переменные не должны лежать в области кода — иначе
студент затирает собственную программу.

### `etalon-js.json` — байтовый эталон из приложения

Сгенерирован `npm run gen-etalon`. Не редактировать руками.

## Что здесь сознательно НЕ реализовано

- **Занятие 3 (bison)** — референс на Python не нужен: там сравнение рукописного
  парсера с генератором, инструмент — настоящий bison (`npm run crosscheck`
  сверяет веб-версию с bison и jison напрямую).
- **Деление** — по методичке это упражнение со звёздочкой (цикл вычитаний
  со сравнением); генератор отказывает с объяснением.
- **Функции/CALL/RET из самостоятельной работы** — ISA машины их поддерживает
  (см. `reference/check.py`), но грамматики мини-языка занятия 1 их не описывают.
